# Georgia Contest Scout

A mobile web app that tracks active radio contests across Georgia — what to enter, how to enter, and when the deadlines hit.

**Live app:** https://muse.ai/s/georgia-contest-scout-xmx06bxgxanxu4xvxe

## What it tracks

Active radio contests at 24 Georgia stations across 7 markets:

- Atlanta
- Augusta
- Savannah
- Macon / Warner Robins
- Columbus
- Albany
- Athens

For each contest: the prize, how to enter (call, text keyword, online), entry windows and deadlines, plus the cluster rules that apply — household cooldown rules shared across station groups (for example, the CMG Atlanta 30-day rule) and scam-shield warnings for lookalike pages and texts.

## This repo

`index.html` is the whole app in a single self-contained file — no build step. Open it in any browser.

## Data freshness

Contest data in this snapshot was verified **November 16, 2026**. Radio contest data goes stale fast — stations end, extend, and replace contests without notice. The [live app](https://muse.ai/s/georgia-contest-scout-xmx06bxgxanxu4xvxe) is the current copy; treat this repo as a snapshot.
